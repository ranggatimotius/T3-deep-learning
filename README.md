# T3 Deep Learning

Repo untuk tugas deep learning berikutnya di T3 Code. Tambahkan brief dan berkas tugas di sini saat tugasnya tersedia.

## Buka di T3 Code

Clone repo, lalu buka foldernya di T3 Code desktop yang sedang berjalan.

```powershell
git clone https://github.com/ranggatimotius/T3-deep-learning.git
cd T3-deep-learning
t3 app .
```

Jika folder ini sudah ada di komputer, buka folder tersebut langsung dari T3 Code. Setelah project terbuka, buat thread baru dan masukkan brief tugas.

## Model untuk project ini

| Peran | Model | Tingkat penalaran | Tanggung jawab |
| --- | --- | --- | --- |
| Orchestrator | Sol 6.2 | High | Membaca brief, menentukan cakupan, dan menggabungkan hasil. |
| Worker | Gemini Hydrogen | Extra High | Mengerjakan bagian yang didelegasikan dan melaporkan hasil verifikasi. |
| Reviewer | Neon | High | Memeriksa hasil terhadap brief, meninjau diff, dan melaporkan temuan sebelum perubahan dipublikasikan. |

Pilih model dan tingkat penalaran ini di T3 saat memulai peran terkait. README ini mencatat preferensi project. Gunakan ID provider dan model yang sesuai dari katalog T3 saat mendelegasikan pekerjaan. Jika pilihan yang diminta tidak muncul, laporkan keterbatasannya dan tunggu arahan sebelum memakai model pengganti.
