# Panduan untuk agen

Baca brief pada thread T3 dan bagian [Model untuk project ini](README.md#model-untuk-project-ini) sebelum memulai tugas.

Untuk repo ini, gunakan Sol 6.2 High sebagai orchestrator, Gemini Hydrogen Extra High sebagai worker, dan Neon High sebagai reviewer. Pilihan worker ini khusus untuk repo ini. Cocokkan provider, model, dan tingkat penalaran dengan katalog delegasi T3. Jika pilihan yang diminta tidak tersedia, laporkan dan minta arahan sebelum mengganti model.
